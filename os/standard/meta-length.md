# Meta description outside 50-160 characters

Pack: seo | Probe type: S | Source: Ebda AI Studio audit 2026-10-26 SEO-10

## Claim
Search snippets truncate near 160 characters and ignore very short descriptions.

## Scenario
Ebda's meta description lengths were off-target on several pages.

## Source candidate
- (low) Static meta description is shorter than 50 or longer than 160 characters.

The probe is a bounded lexical check. It reports candidates with file/line evidence and does not claim that a local guard name proves the guard is effective. A judge must read the code behind every hit (reachability, middleware, framework semantics) before grading.

## Fix template
Write 70-155 character descriptions per page and locale.
