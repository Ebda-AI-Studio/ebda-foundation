v1.0.0 means: the foundation is the only source of the shared base in both products, nobody pins anything by hand, and a new product can start from it. It is NOT tagged yet (F11, plan `business/ebda/plans/2026-10-26-ebda-foundation.md` section 4). Tag it only when every box below is true and the evidence is written next to it. Status lives in the program register, not here: this is the gate, not a status list.

