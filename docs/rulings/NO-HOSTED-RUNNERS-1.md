# NO-HOSTED-RUNNERS-1

Ruling NO-HOSTED-RUNNERS-1 - no foundation workflow runs on a GitHub-hosted runner, and none can fall back to one. Every `runs-on` is a repo variable with the Mac fallback `'["ebda-mac-light"]'` (the six measured-short jobs use `vars.EBDA_ANY_RUNS_ON || vars.EBDA_RUNS_ON || '["ebda-mac-light"]'` under a `# short-job:` comment); the four `setup-node` remote `cache:` inputs are gone; `ops/workflow-lint.mjs` fails any `ubuntu-` / `windows-` / `macos-` image name in a `runs-on` and any `setup-node` `cache:`, and the `# hosted-only:` exception is removed. `test/workflow-lint.test.ts` runs the lint over the real workflow files (mutation: a hosted fallback in pr-quality.yml fails it). Evidence: Ahmad, 2026-11-16 (no hosted minutes); measured on origin/main 2026-11-18: 17 `ubuntu*` references in `.github`, 11 of them `runs-on`. Cost if wrong: a job whose variable is unset waits for a Mac runner instead of running hosted (GitHub queues, it does not fail).

Decisions that change a documented property, for the controller's review:
- `prod-watch.yml` was hosted-only on purpose (outside-in: off Cloudflare and off the Egyptian ISP that blocks Cloudflare's range from the Mac). It cannot keep that property on a Mac runner. The workflow is already `disabled_manually` (last run 2026-11-16T01:31Z); its `runs-on` is now the Mac form so the lint holds, and the file says so. The brain's Cron Trigger is the primary probe loop (AIOS-7).
- `notify-failure`-style alert jobs no longer have an independent hosted path ("stays on ubuntu-latest, fail-open" in `os/standard/cicd.md` row 5): a Mac-pool outage can now also silence the alert that reports it. `os/standard/cicd.md` rows 5 and 8 and the runner-guard paragraph are updated.

Left alone, not `runs-on` (listed, not changed): `os/standard/audit-gating.md` lines 52-54, `os/standard/dreaming-cycle.md` line 65, `os/standard/rules/bash-ops.md` line 13 (all still say alert/safety-net jobs stay on `ubuntu-latest`), the synthetic `runs-on: ubuntu-latest` fixtures in `test/merge-gate-required.test.ts`, and `docs/plans/*`.
