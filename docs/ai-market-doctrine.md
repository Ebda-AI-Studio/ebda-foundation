# ai-market-doctrine — What to Build and What to Sell

## The thesis

Building is a commodity. Every builder has the same models, the same speed, the same access.
The gap is no longer who CAN build — it is who builds something someone pays for.

## The nine rules

1. **Sell the eliminated monthly cost, not the feature.** A merchant losing 3k/month to a manual
   process pays 500/month to remove it. Buyers do not evaluate architecture or stack. The only
   question is "does this fix the thing costing me money every month?"
2. **Distribution is the moat; building is not.** Audience → pain → build → paid, IN THAT ORDER.
   Build-first-then-find-customers is backwards.
3. **Depth beats breadth.** One product converting at 5% beats ten converting at zero.
   Volume is not velocity; revenue is velocity.
4. **Credibility is deployed client work**, not a portfolio of personal builds.
5. **Be the second call.** Much of this market is businesses whose first AI builder failed.
   Cleaning up a failed project is a stronger position than pitching greenfield.
6. **Specialisation wins every sales conversation.** Specific outcome, specific business type,
   specific proof. Selling everything to everyone sells nothing to no one.
7. **The gap is WORKFLOW, not technology.** Horizontal SaaS is built for every industry and
   customised for none. The rules that matter (a salon's stylist specialities, a contractor's
   service zones and drive time, a dentist's insurance verification) are exactly what no generic
   platform encodes.
8. **Build for ONE operator, then productise.** The second customer in the same vertical costs
   almost nothing — same problem, same rules, different logo.
9. **Domain depth is the moat no model replicates.** A model writes code fast; it cannot know why
   a compliance workflow routes through three departments.

## Standing gate — apply before any NEW project plan

The `/ecosystem-research` trigger already fires before a new project plan. Add these four
questions to it, answered in order. **A "no" on 1 or 2 is a stop, not a caveat.**

1. Does the audience already exist, or is this build-first? (rule 2)
2. What recurring cost does this delete, in local-currency cost per month (EGP, USD, or the buyer's own), for a named buyer? (rule 1)
3. Is this one operator's real workflow, or a generic platform for nobody? (rules 7, 8)
4. Is this depth on an existing bet, or another parallel bet? (rule 3)
