# Core component specs (v1)

Specs, not code: each product implements them with its own stack and passes the guard rules. Sizes come from `tokens.ts`.

| Component                 | Spec                                                                                                                                                                                                                                                                                                                                        |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Button                    | sm 32 / md 40 (44 phones) / lg 44, radius control, 14px (13 sm), variants default (filled gold, one per view), outline, secondary, ghost, soft (selected tab/segment/chip), destructive, link. Icon-only: square of the same height, `aria-label`. No hover translate. `disabled` 50% opacity, `isLoading` shows a spinner and `aria-busy`. |
| Input / Select / Textarea | height = Button md (40, 44 phones), radius control, 16px on phones (iOS zoom), label above (6px gap), helper 13px muted, error 13px destructive-ink with an icon, never colour alone. Programmatic label always.                                                                                                                            |
| Nav item                  | sidebar 44 (icon 20, label 14/500), hub tab 40 (44 phones), settings rail 40, bottom bar 56 with 12px labels. Active = `bg-primary/15` + `primary-ink`; inactive muted; hover accent. Locked feature: padlock badge, the page shows the upgrade card.                                                                                       |
| Page header               | title 20 (h1, one per page), optional subtitle 14 muted, primary action at the inline-end, secondary beside it; on phones actions wrap under the title, never grow the bar past 57px.                                                                                                                                                       |
| Card                      | surface radius 14, hairline border, elevation 1 only when it floats, padding 16 (lists) / 24 (forms). Card title 18.                                                                                                                                                                                                                        |
| Table                     | 40px rows, header 13 / 500 (Arabic) sticky, row actions in one overflow menu, numbers tabular and end-aligned, density never below 40px, empty state inside the card.                                                                                                                                                                       |
| Status pill               | pill radius, 12px, `bg-<role>/10` + `<role>-ink`, an icon or text label (never colour alone).                                                                                                                                                                                                                                               |
| Plan-locked card          | lock badge, feature title, one sentence on what it unlocks, "available on <plan> and above", filled upgrade button + outline "see plans"; no retry, no destructive colour.                                                                                                                                                                  |
| Error / crash state       | page-level boundary that keeps the shell; title, one friendly sentence, retry + home; error id only; never the JS message.                                                                                                                                                                                                                  |
| Toast / dialog            | toast z 60, 4s, mirrors in RTL; dialog radius surface, elevation 3, focus trap, Escape closes, primary action at the inline-end.                                                                                                                                                                                                            |
| Empty value               | "not set" in words (or an explicit dash with an `aria-label`), never a bare dash for unknown vs zero.                                                                                                                                                                                                                                       |
| Skeleton | Holds the final height of the region it stands in for (rows 56, cards 96, panel 160), surface or control radius, `sand` fill with an opacity pulse (1.2s, 150ms-250ms rule does not apply to the pulse, it stops under reduced motion), `role="status"` + `aria-label`. Replaces a bare "..."; never text. |
