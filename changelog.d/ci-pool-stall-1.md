- CI-POOL-STALL-1 (`os/cloud/brain/src/watchers/ci-pool.ts`, `classify.ts`, `run.ts`, brain tests): a Cloudflare-side watcher (every 15 min) raises ONE deduped P1 `ci-pool-stall` per repo when a CI run has been queued more than `CI_QUEUE_MIN` (60) minutes and nothing is running, the signal that the Mac runner pool is down now that no workflow has a hosted fallback (NO-HOSTED-RUNNERS-1). Queued runs older than `CI_QUEUE_MAX_MIN` (360) are ghosts no runner takes and are ignored, so one ghost at a quiet hour cannot page nightly. A long queue while runs are in progress is saturation and does not alert; an API failure is a watcher-error, never healthy.
