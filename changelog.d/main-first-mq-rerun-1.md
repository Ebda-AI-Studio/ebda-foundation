- MAIN-FIRST-MQ-1 (`os/ops/main-first.sh`, `os/ops/tests/main-first.test.sh`): no re-request of a NON-launch PR run (neither the post-green re-request nor the lease release) while a merge-queue run (event `merge_group`, branch `gh-readonly-queue/*`) is queued or in progress (held runs stay in the ledger; an unreadable queue fails closed), and a non-launch run is re-requested at most ONCE per head (`.rerun.once` records `run sha`; a second cancel of the same head drops the run instead of reviving it, which breaks the cancel/revive loop). Launch-list PRs and the drain batch are never held or once-limited. Replaces the temporary `MAIN_FIRST_RERUN_CAP=0` / `MAIN_FIRST_LEASE_RERUN_CAP=0` caps. Install after merge.
